Inspect checks the applications your organization uses against the controls you select. It collects evidence from APIs or the application's interface and shows you the observations behind each result.

For example, an MFA control asks whether the required accounts have MFA enforced. Inspect reads the available configuration, evaluates it against the control, and explains the result. You can review the records it collected and, for browser inspections, the available screenshots and session replay.

## Start with an application and a question

Choose the application tenant you want to inspect, provide access, and select a control set. Common checks cover administrator access, authentication, external sharing, and other security settings.

The browser agent can navigate an application without vendor documentation. Planning API requests requires documentation for the API operations. The [application onboarding guide](/inspect/adding-an-application) explains the access each method needs and how to get help with setup.

## Choose what to learn

| Purpose | What you get |
| --- | --- |
| Explore | Evidence showing what Inspect can observe for the selected controls. |
| Evaluate | An evaluation of the observed evidence against each control, with a written explanation. |
| Drift | A comparison with a compatible earlier inspection to show what changed. |

Review the result for each control. A finished inspection can include incomplete or failed checks, so the number of finished controls is not a compliance score. Missing evidence and collection failures need investigation before you draw a conclusion about the application's configuration.
