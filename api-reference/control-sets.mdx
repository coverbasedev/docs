These endpoints let you build and tune the control sets your vendors are assessed against. A **control set** (`cbctst_...`) holds **sections** (`cbctsn_...`) and **controls** (`cbctrl_...`). Settings on the set apply to every control in it: AI evaluation guidance, strictness, evidence sources, applicability and Zero Touch eligibility.

Controls are versioned. A material edit to a control creates a new version with a new `id` and the same `perma_id`, so past assessments keep the text they were evaluated on. Control sets and sections are edited in place. Every change to a set or control is recorded in its activity, as the same edit in the dashboard is.

All endpoints are org-scoped to the API key. See [API conventions](/conventions) for shared behavior. None of these honor `Idempotency-Key`.

Archiving or unarchiving a set or section also needs `control_set:archive:org`, and archiving a control needs `control:archive:org`. Archiving and unarchiving stay with signed-in users: in every organization, a request made with an API key that archives or unarchives returns `403 api_key_not_allowed`.

## Control set object

<ResponseField name="id" type="string">Control set ID (`cbctst_...`).</ResponseField>
<ResponseField name="name" type="string">Name.</ResponseField>
<ResponseField name="control_set_type" type="string">`policy`, `questionnaire` or `internal`.</ResponseField>
<ResponseField name="description" type="string | null">Description.</ResponseField>
<ResponseField name="is_archived" type="boolean">Whether the set is archived.</ResponseField>
<ResponseField name="is_applied_to_all" type="boolean">Whether the set applies to every vendor.</ResponseField>
<ResponseField name="applied_to_tag_ids" type="string[]">Tags whose vendors the set applies to.</ResponseField>
<ResponseField name="inherent_risk_level_ids" type="string[]">Inherent risk levels whose vendors the set applies to.</ResponseField>
<ResponseField name="is_zero_touch_eligible" type="boolean">Whether Zero Touch assessments can use the set.</ResponseField>
<ResponseField name="eval_strictness" type="integer">How strictly the AI judges evidence, from `1` (lenient) to `5` (skeptical). New sets use `3`.</ResponseField>
<ResponseField name="eval_instructions" type="string | null">Guidance the AI applies when it evaluates every control in the set.</ResponseField>
<ResponseField name="remediation_instructions" type="string | null">Guidance for remediation wording.</ResponseField>
<ResponseField name="is_web_search_enabled" type="boolean">Whether evaluations search the web.</ResponseField>
<ResponseField name="web_search_instructions" type="string | null">Guidance for web search.</ResponseField>
<ResponseField name="evidence_sources" type="object[]">The [evidence sources](#evidence-source-object) the AI draws on.</ResponseField>
<ResponseField name="restrict_evidence_to_sources" type="boolean">Whether the AI uses only the listed evidence sources.</ResponseField>
<ResponseField name="document_requirement" type="object[]">Documents vendors provide, each `{ "document_type": "<slug>", "is_required": true }`.</ResponseField>
<ResponseField name="risk_domain_id" type="string | null">Risk domain the set rolls up to.</ResponseField>
<ResponseField name="vendor_rating_weight" type="number | null">The set's share of the vendor rating. `null` leaves it out of the weighting.</ResponseField>
<ResponseField name="scale_id" type="string | null">The scale every live control uses. `null` when the controls use different scales or none.</ResponseField>
<ResponseField name="watcher_ids" type="string[]">Users who watch the set.</ResponseField>
<ResponseField name="library_slug" type="string | null">The library template the set was copied from.</ResponseField>
<ResponseField name="library_revision" type="integer | null">The template revision the copy carries.</ResponseField>
<ResponseField name="questionnaire_id" type="string | null">The questionnaire derived from the set.</ResponseField>
<ResponseField name="control_count" type="integer">Number of live controls.</ResponseField>
<ResponseField name="created_at" type="integer">Unix timestamp (seconds).</ResponseField>

### Evidence source object

<ResponseField name="source_type" type="string">`document`, `factsheet`, `web_search` or `contracts`.</ResponseField>
<ResponseField name="document_types" type="string[]">For `document`: the document types to search. Empty means every type.</ResponseField>
<ResponseField name="instructions" type="string | null">How the AI uses the source.</ResponseField>
<ResponseField name="is_required" type="boolean">When `true`, the AI cites this source or flags its absence.</ResponseField>
<ResponseField name="match" type="string">For a required `document` source: `any` (one type is enough) or `all`.</ResponseField>
<ResponseField name="minimum_credibility" type="string">For `web_search`: the lowest publisher credibility accepted.</ResponseField>
<ResponseField name="denied_web_evidence_types" type="string[]">For `web_search`: page types to exclude.</ResponseField>

A `contracts` source shares contract terms with every evaluation, so adding one needs `contract:read:org`.

## Create a control set

<ParamField path="method" type="POST">
  `POST /v1/control-sets`
</ParamField>

Returns `201 Created` with the [control set object](#control-set-object). To copy a framework template with its sections and controls, send its slug from [the library](#list-library-templates) as `use_library`.

### Request body

<ParamField body="name" type="string" required>Name.</ParamField>
<ParamField body="control_set_type" type="string" default="policy">`policy`, `questionnaire` or `internal`. A library copy takes the template's type.</ParamField>
<ParamField body="description" type="string">Description.</ParamField>
<ParamField body="is_applied_to_all" type="boolean" default="false">Apply the set to every vendor.</ParamField>
<ParamField body="applied_to_tag_ids" type="string[]">Tags whose vendors the set applies to.</ParamField>
<ParamField body="is_zero_touch_eligible" type="boolean">Make the set available to Zero Touch assessments.</ParamField>
<ParamField body="eval_strictness" type="integer">From `1` (lenient) to `5` (skeptical).</ParamField>
<ParamField body="eval_instructions" type="string">Set-level AI guidance.</ParamField>
<ParamField body="remediation_instructions" type="string">Remediation guidance. A library copy ignores it.</ParamField>
<ParamField body="is_web_search_enabled" type="boolean" default="false">Let evaluations search the web.</ParamField>
<ParamField body="web_search_instructions" type="string">Web search guidance, at most 2000 characters.</ParamField>
<ParamField body="evidence_sources" type="object[]">[Evidence sources](#evidence-source-object).</ParamField>
<ParamField body="restrict_evidence_to_sources" type="boolean" default="true">Use only the listed evidence sources.</ParamField>
<ParamField body="document_requirement" type="object[]">Required documents. A library copy ignores it.</ParamField>
<ParamField body="risk_domain_id" type="string">Risk domain. A library copy otherwise takes the template's domain.</ParamField>
<ParamField body="scale_id" type="string">Scale for every control of the set.</ParamField>
<ParamField body="watcher_ids" type="string[]">Users who watch the set.</ParamField>
<ParamField body="use_library" type="string">Library template slug to copy.</ParamField>

### Example request

```bash cURL
curl -X POST "https://api.coverbase.app/v1/control-sets" \
  -H "Authorization: Bearer ak_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "SOC 2 for critical vendors",
    "use_library": "soc2",
    "is_zero_touch_eligible": true,
    "eval_strictness": 4
  }'
```

## Update a control set

<ParamField path="method" type="PATCH">
  `PATCH /v1/control-sets/{control_set_id}`
</ParamField>

Only the fields you send change. To clear `risk_domain_id` or `vendor_rating_weight`, send `null`. An archived set returns `409 control_set_archived`. Returns the updated [control set object](#control-set-object).

### Request body

Every create field except `control_set_type` and `use_library`, plus:

<ParamField body="inherent_risk_level_ids" type="string[]">Inherent risk levels the set applies to. Replaces the list.</ParamField>
<ParamField body="vendor_rating_weight" type="number">Share of the vendor rating, greater than 0 and at most 1000.</ParamField>
<ParamField body="is_archived" type="boolean">Archive the set with its sections and controls. Needs `control_set:archive:org`. An API key gets `403 api_key_not_allowed`.</ParamField>

Lists you send (`applied_to_tag_ids`, `evidence_sources`, `document_requirement`, `watcher_ids`) replace the stored list. A `scale_id` applies to every live control.

## Update a control

<ParamField path="method" type="PATCH">
  `PATCH /v1/controls/{control_id}`
</ParamField>

Takes every create field, all optional, plus the fields below. Only the fields you send change. Returns the resulting [control object](#control-object).

A material change creates a new version, and the response carries its new `id`. These fields are material: `expectation`, `question`, `question_additional_instructions`, `response_type`, `eval_instructions`, `weight`, `is_required`, `control_section_id`, `significant_deficiency_level_id`, `significant_deficiency_scope` and `options`. Other fields change the version in place.

<ParamField body="evidence_requirement" type="string">`document_required` or `attestation_only`. Send `null` to clear it.</ParamField>
<ParamField body="significant_deficiency_level_id" type="string">A risk scale level. Send `null` to clear the floor.</ParamField>
<ParamField body="significant_deficiency_scope" type="string">What the floor applies to. Send `null` to clear it.</ParamField>
<ParamField body="control_section_id" type="string">Move to this section of the same set. Send `unassigned` to remove it from its section.</ParamField>
<ParamField body="options" type="object[]">Answer choices to add or edit. A new choice has no `id`. To edit an existing choice, send its `id` and `perma_id` with the fields to change, or `"is_archived": true` to remove it.</ParamField>
<ParamField body="is_archived" type="boolean">Archive or unarchive the control. Needs `control:archive:org`. An API key gets `403 api_key_not_allowed`.</ParamField>

If you edit an earlier version, the request returns `409 control_superseded` with the latest version's ID in the message.

### Example request

```bash cURL
curl -X PATCH "https://api.coverbase.app/v1/controls/cbctrl_1234" \
  -H "Authorization: Bearer ak_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "eval_instructions": "Accept a SOC 2 bridge letter dated within 3 months.",
    "evidence_requirement": null
  }'
```

## Move, archive or unarchive controls

<ParamField path="method" type="POST">
  `POST /v1/controls/bulk-action`
</ParamField>

Moves many controls into one section, or archives or unarchives them. If any control fails, nothing changes. Each moved control takes a new version. Returns `{ "action": "add_to_section", "control_count": 2 }`.

<ParamField body="action" type="string" required>`add_to_section`, `archive` or `unarchive`. Archiving and unarchiving needs `control:archive:org`, and an API key gets `403 api_key_not_allowed`.</ParamField>
<ParamField body="control_ids" type="string[]" required>From 1 to 500 control IDs.</ParamField>
<ParamField body="control_section_id" type="string">Destination section. Required for `add_to_section`.</ParamField>

## Review a framework reference

<ParamField path="method" type="PATCH">
  `PATCH /v1/controls/{control_id}/framework-references/{index}`
</ParamField>

Accepts or rejects a suggested framework reference on a control. Only an accepted reference counts toward framework coverage.

<ParamField body="action" type="string" required>`accept`, `reject` (removes the reference) or `no_clause` (records that the framework has no matching clause).</ParamField>

Returns `framework_references`, the control's references after the change, or `404 framework_reference_not_found`.

## List library templates

<ParamField path="method" type="GET">
  `GET /v1/control-set-library`
</ParamField>

Returns an `items` array of templates you can copy with `use_library`. Each has `slug`, `name`, `num_controls`, `control_set_type`, `audience` (`vendor` or `internal`), `description` and `is_web_search_enabled`.

## List library updates

<ParamField path="method" type="GET">
  `GET /v1/control-set-library/updates`
</ParamField>

Returns an `items` array of the org's library copies whose template has a newer revision. Each has `control_set_id`, `control_set_name`, `template_slug`, `template_name`, `from_revision`, `to_revision`, `vendor_count` and `changes`. Each change has `external_idx`, `kind` (`added`, `changed` or `removed`), `expectation`, `previous_expectation` and `is_conflict` (the copy was edited by hand).

## Apply a library update

<ParamField path="method" type="POST">
  `POST /v1/control-sets/{control_set_id}/apply-library-update`
</ParamField>

Brings a library copy to its template's latest revision. Changed controls take a new version. Controls edited by hand stay as they are. Returns `applied` and `conflicts` (lists of `external_idx`) and `to_revision`, or `409 no_library_update`.

## Draft a reassessment of affected vendors

<ParamField path="method" type="POST">
  `POST /v1/control-sets/{control_set_id}/reassess-affected`
</ParamField>

Returns `201 Created` with `reassessment_id` and `vendor_count`. Drafts one [reassessment](/api-reference/reassessments) of the vendors assessed with the set.

<ParamField body="vendor_ids" type="string[]">Vendors to include. Without it, every vendor assessed with the set is included.</ParamField>

## Error responses

| Status | Body | When |
| ------ | ---- | ---- |
| 403 | `{"detail": {"code": "api_key_not_allowed", ...}}` | An API key archives or unarchives a set, section or control. |
| 403 | `{"detail": "Missing required permission."}` | The caller lacks the permission, including `contract:read:org` for a `contracts` evidence source. |
| 404 | `{"detail": {"code": "control_set_not_found", ...}}` | The set does not exist in the API key's org. |
| 404 | `{"detail": {"code": "control_section_not_found", ...}}` | The section does not exist. |
| 404 | `{"detail": {"code": "control_not_found", ...}}` | The control does not exist. |
| 409 | `{"detail": {"code": "control_set_archived", ...}}` | Editing an archived set. |
| 409 | `{"detail": {"code": "duplicate_external_idx", ...}}` | The set already has a control with that `external_idx`. |
| 409 | `{"detail": {"code": "control_superseded", ...}}` | Editing an earlier version of a control. |
| 409 | `{"detail": {"code": "no_library_update", ...}}` | The set has no newer template revision. |
| 422 | `{"detail": {"code": "invalid_control_set", ...}}` | The set was rejected, for example an unknown library slug or risk domain. |
| 422 | `{"detail": {"code": "invalid_control_section", ...}}` | The section is not a live section of the same set. |
| 422 | `{"detail": {"code": "invalid_control_option", ...}}` | An answer choice has no name, or an edited choice has no `perma_id`. |
| 422 | `{"detail": {"code": "invalid_control_update", ...}}` | The control cannot take the change, for example an archived version. |
| 422 | `{"detail": {"code": "no_assessed_vendors", ...}}` | None of the vendors were assessed with the set. |
