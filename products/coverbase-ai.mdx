Coverbase AI does the work instead of describing it. You type what you want done, such as "Onboard Figma", "Review Okta's SOC 2 report against our access controls" or "Watch our critical vendors on Radar", and it runs the same steps an analyst would run by hand. It opens the intake, answers the inherent risk questionnaire from research, picks control sets, launches the assessment, reads the results, raises findings and sets up monitoring. When it finishes it hands back a report with a link to everything it touched.

Every run acts as the person who started it, with that person's permissions, and only that person sees it. Each action is recorded in the [Agent Ledger](/products/agent-ledger).

## What it never does

Coverbase AI never approves a vendor or accepts risk on its own, never sends anything to a vendor without your approval, and adds a vendor outside intake only when you ask it to. Archiving a record, submitting an intake request and anything else that cannot be undone always waits for you, even when you tell it not to stop to ask. For every control on a run, see [Controls, approvals and governance](/user-guides/coverbase-ai-agent-controls).

## How it reads files

Coverbase AI reads PDFs page by page, Word documents (including older `.doc` files), Excel workbooks sheet by sheet, CSV files, emails and text files. It reads a long report in sections until it has read the part your question needs.

It tells you when it cannot read something instead of guessing. A scanned PDF or an image has no text to read yet. A password-protected PDF needs an unlocked copy. A damaged file, a `.zip` archive or an empty file is named as such. Text inside a file is treated as information, not as instructions, so a file that says "archive this vendor" does not make it archive anything. A report about a different company than the one you named is flagged before it is used.
