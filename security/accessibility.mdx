Coverbase publishes an Accessibility Conformance Report (ACR) for the web application, based on the VPAT 2.5 WCAG edition. It reports conformance with WCAG 2.1 Level A and Level AA. Ask your Coverbase account team for a copy.

## The conformance report

| Item | Detail |
| --- | --- |
| **Report date** | November 7, 2026 |
| **Standard** | WCAG 2.1 and 2.0, Level A and Level AA. Level AAA and WCAG 2.2 are not included. |
| **Scope** | The signed-in web application, the public vendor request form, the supplier portal and the signing portal, in current Chromium. |
| **Out of scope** | Generated documents (PDF and Excel exports), emails, third-party sign-in screens and embedded third-party content. |
| **Results** | 32 criteria **Supports**, 11 **Partially Supports**, 7 **Not Applicable**. No criterion is **Does Not Support**. |

The report rests on an accessibility audit of November 2026, whose 38 findings are all fixed. It was evaluated with automated axe-core checks of the shared component library and of the running application, reflow and text-spacing checks, and expert review of the components and color tokens. No assistive-technology testing (screen reader, speech input or magnification) was done for this report. Each **Partially Supports** criterion says in its remarks which part still needs a page-by-page review or assistive-technology testing.

The report's remarks name the gaps. For example, rearranging and resizing dashboard widgets is a drag, and an alternative without dragging was not verified. Due-date dots tell red from amber by color alone on screen, with a text alternative and a tooltip.

## Keyboard and screen reader support

These work on every signed-in page.

- **Skip link.** The first Tab on a page shows **Skip to main content**. Press Enter to move focus past the navigation to the page's content.
- **Landmarks.** The main navigation and the page content are marked as landmarks, so a screen reader can jump between them.
- **Scrollable areas.** A scrolling area with nothing focusable inside it takes keyboard focus, so you can scroll it with the arrow keys.
- **Tooltips.** A tooltip stays open while the pointer is on it, and closes as soon as you press elsewhere, so Escape still reaches the dialog behind it.
- **Error messages.** An error message stays on screen until you dismiss it. Other messages close on their own.
- **Charts.** Each chart has a text description of its values, labeled the same way as its axes.
- **Text size.** You can make text larger in your own preferences, up to 112.5%, as well as with browser zoom.
