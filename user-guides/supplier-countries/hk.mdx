A supplier whose bank account is held in Hong Kong SAR sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Required | up to 60 characters |  |
| Bank code | Suggested | 3 characters, digits only | 3 digits. |
| Branch code | Suggested | 3 characters, digits only | 3 digits. |
| Account number | Required | 6 to 12 characters, digits only |  |
| SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, BOFAUS3N. Needed for a payment by wire. |
| Account type | Required | no length limit, one of: checking, savings | Checking unless the bank issued the account as a savings account. |
| Intermediary bank country code | Optional | 2 characters, letters only | Two-letter country code, for example, US. |
| Intermediary bank city | Optional | up to 60 characters |  |
| Account number at the intermediary bank | Optional | up to 34 characters |  |
| Intermediary bank name | Optional | up to 60 characters |  |
| Intermediary branch number | Optional | up to 30 characters |  |
| Intermediary IBAN | Optional | 15 to 34 characters, letters and digits, IBAN MOD-97 check |  |
| Intermediary SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, CHASUS33. |

### IBAN

Hong Kong SAR does not use IBANs. Accounts are identified by the fields above.

### Currency

Every account also records its currency. The form opens on HKD, the currency of Hong Kong SAR, and the supplier changes it for an account held in another currency.
