A supplier whose bank account is held in Portugal sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Optional | up to 60 characters |  |
| Bank code | Required | 4 characters, digits only |  |
| Branch code | Required | 4 characters, digits only |  |
| Account number | Required | up to 11 characters, digits only |  |
| Check digit | Optional | 2 characters, digits only, Portuguese account check digits |  |

### IBAN

An IBAN is required for Portugal. It is 25 characters and is checked against the ISO 7064 MOD-97 algorithm, which catches a mistyped or transposed digit before the details reach your finance system.

## Tax and company registrations

| Registration | Requirement | Format | Notes |
| --- | --- | --- | --- |
| NIF | Required | 9 characters, digits only, NIF check digit | 9 digits. |

After a registration is saved, Coverbase checks it against the EU VIES service in the background. That check never blocks the supplier: it annotates the record once it completes, and a reviewer can retry it.

## Where these rules come from

Oracle Fusion Cash Management 26c PT validations; NIB check digits.

The rules on this page are confirmed against a primary source, so they are enforced strictly.

Configuration version `2026.08.1`. Your organization can override any of these rules for its own suppliers.
