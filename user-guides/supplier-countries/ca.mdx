A supplier whose bank account is held in Canada sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Optional | up to 60 characters |  |
| Institution number | Required | 3 characters, digits only | 3 digits, for example, 003 for RBC. |
| Transit number | Required | 5 characters, digits only | 5 digits, the branch that holds the account. |
| Account number | Required | up to 12 characters |  |
| SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, BOFAUS3N. Needed for a payment by wire. |
| Account type | Optional | no length limit, one of: checking, savings | Checking unless the bank issued the account as a savings account. |
| Intermediary bank country code | Optional | 2 characters, letters only | Two-letter country code, for example, US. |
| Intermediary bank city | Optional | up to 60 characters |  |
| Account number at the intermediary bank | Optional | up to 34 characters |  |
| Intermediary bank name | Optional | up to 60 characters |  |
| Intermediary branch number | Optional | up to 30 characters |  |
| Intermediary IBAN | Optional | 15 to 34 characters, letters and digits, IBAN MOD-97 check |  |
| Intermediary SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, CHASUS33. |

### IBAN

Canada does not use IBANs. Accounts are identified by the fields above.

### Currency

Every account also records its currency. The form opens on CAD, the currency of Canada, and the supplier changes it for an account held in another currency.

## Tax and company registrations

| Registration | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Business Number (BN) | Required | 9 to 15 characters, letters and digits | 9 digits, optionally followed by a program account suffix (for example, RT0001). |

## Country rules

- Postal codes are checked against the national format. A postal code that does not match produces a warning, not a rejection.

## Where these rules come from

Oracle Fusion Cash Management 26c CA validations; Payments Canada routing number (3-digit institution, 5-digit transit) split into its two fields.

The rules on this page are confirmed against a primary source, so they are enforced strictly.

Configuration version `2026.10.5`. Your organization can override any of these rules for its own suppliers.
