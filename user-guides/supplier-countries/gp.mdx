## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Optional | up to 60 characters |  |
| Bank code | Optional | no length limit |  |
| Branch code | Optional | no length limit |  |
| Account number | Required | no length limit |  |
| Check digit | Optional | no length limit |  |
| SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, e.g. BOFAUS3N. Needed for a payment by wire. |
| Account type | Optional | no length limit, one of: checking, savings | Checking unless the bank issued the account as a savings account. |

### IBAN

An IBAN is required for Guadeloupe. It is 27 characters and is checked against the ISO 7064 MOD-97 algorithm, which catches a mistyped or transposed digit before the details reach your finance system.
