A supplier whose bank account is held in Mexico sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Optional | up to 60 characters |  |
| Bank code | Optional | no length limit, digits only |  |
| Branch code | Optional | no length limit, digits only |  |
| Account number | Required | 10 to 11 characters, digits only | 10 or 11 digits. |
| Check digit | Optional | no length limit, digits only |  |
| CLABE | Optional | 18 characters, digits only, CLABE check digit | 18 digits. |

### IBAN

An IBAN is optional for Mexico. It is up to 34 characters and is checked against the ISO 7064 MOD-97 algorithm, which catches a mistyped or transposed digit before the details reach your finance system.

## Tax and company registrations

| Registration | Requirement | Format | Notes |
| --- | --- | --- | --- |
| RFC | Required | 12 to 13 characters, letters and digits, RFC control character | 12 characters for companies, 13 for individuals. |

## Where these rules come from

Oracle Fusion Cash Management 26c MX validations; Banxico CLABE spec.

The rules on this page are confirmed against a primary source, so they are enforced strictly.

Configuration version `2026.08.1`. Your organization can override any of these rules for its own suppliers.
