A supplier whose bank account is held in Nigeria sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Required | up to 60 characters |  |
| Bank code | Required | 3 characters, digits only | 3-digit CBN institution code. |
| Branch code | Suggested | 5 characters, digits only |  |
| Account number | Required | 10 characters, digits only, NUBAN check digit | 10-digit NUBAN. |
| SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, BOFAUS3N. Needed for a payment by wire. |
| Account type | Optional | no length limit, one of: checking, savings | Checking unless the bank issued the account as a savings account. |
| Intermediary bank country code | Optional | 2 characters, letters only | Two-letter country code, for example, US. |
| Intermediary bank city | Optional | up to 60 characters |  |
| Account number at the intermediary bank | Optional | up to 34 characters |  |
| Intermediary bank name | Optional | up to 60 characters |  |
| Intermediary branch number | Optional | up to 30 characters |  |
| Intermediary IBAN | Optional | 15 to 34 characters, letters and digits, IBAN MOD-97 check |  |
| Intermediary SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, CHASUS33. |

### IBAN

Nigeria does not use IBANs. Accounts are identified by the fields above.

### Currency

Every account also records its currency. The form opens on NGN, the currency of Nigeria, and the supplier changes it for an account held in another currency.

## Where these rules come from

CBN NUBAN specification (weights 3,7,3 over bank code + serial).

The rules on this page are confirmed against a primary source, so they are enforced strictly.

Configuration version `2026.10.4`. Your organization can override any of these rules for its own suppliers.
