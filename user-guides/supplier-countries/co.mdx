A supplier whose bank account is held in Colombia sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Optional | up to 60 characters |  |
| Bank code | Optional | no length limit, digits only |  |
| Branch code | Optional | no length limit, digits only |  |
| Account number | Required | up to 20 characters |  |
| Check digit | Optional | no length limit, digits only | Optional. Only if your bank statement shows a separate check digit; leave blank if it does not. |
| Branch name | Optional | up to 60 characters | Required by Citibank Colombia when the 3-digit branch code is not supplied. |
| Bank's taxpayer ID (NIT) | Optional | up to 15 characters, digits only, NIT verification digit | The NIT of the bank holding the account, not the supplier's own NIT. Leave blank if it is not on the bank statement. |
| SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, BOFAUS3N. Needed for a payment by wire. |
| Account type | Optional | no length limit, one of: checking, savings | Checking unless the bank issued the account as a savings account. |
| Intermediary bank country code | Optional | 2 characters, letters only | Two-letter country code, for example, US. |

| Intermediary branch number | Optional | up to 30 characters |  |
| Intermediary IBAN | Optional | 15 to 34 characters, letters and digits, IBAN MOD-97 check |  |
| Intermediary SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, CHASUS33. |

### IBAN

Colombia does not use IBANs. Accounts are identified by the fields above.

## Where these rules come from

The rules on this page are confirmed against a primary source, so they are enforced strictly.
