A supplier whose bank account is held in Germany sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Optional | up to 60 characters |  |
| Bankleitzahl | Optional | 8 characters, digits only |  |
| Branch code | Optional | 8 characters, digits only |  |
| Account number | Required | up to 10 characters, digits only |  |
| Check digit | Optional | 1 characters, digits only, German account check digit |  |

### IBAN

An IBAN is required for Germany. It is 22 characters and is checked against the ISO 7064 MOD-97 algorithm, which catches a mistyped or transposed digit before the details reach your finance system.

## Tax and company registrations

| Registration | Requirement | Format | Notes |
| --- | --- | --- | --- |
| VAT number (USt-IdNr.) | Required | 11 characters, letters and digits, German VAT check digit | DE followed by 9 digits. |

After a registration is saved, Coverbase checks it against the EU VIES service in the background. That check never blocks the supplier: it annotates the record once it completes, and a reviewer can retry it.

## Country rules

- The bank code and branch code must match each other.
