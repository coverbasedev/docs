A supplier whose bank account is held in India sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Optional | up to 60 characters |  |
| IFSC Code | Suggested | 11 characters, letters and digits | 11 characters, for example, HDFC0000123. |
| Account number | Required | up to 18 characters, letters and digits |  |
| SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, BOFAUS3N. Needed for a payment by wire. |
| Account type | Optional | no length limit, one of: checking, savings | Checking unless the bank issued the account as a savings account. |
| Intermediary bank country code | Optional | 2 characters, letters only | Two-letter country code, for example, US. |
| Intermediary bank city | Optional | up to 60 characters |  |
| Account number at the intermediary bank | Optional | up to 34 characters |  |
| Intermediary bank name | Optional | up to 60 characters |  |
| Intermediary branch number | Optional | up to 30 characters |  |
| Intermediary IBAN | Optional | 15 to 34 characters, letters and digits, IBAN MOD-97 check |  |
| Intermediary SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, CHASUS33. |

### IBAN

India does not use IBANs. Accounts are identified by the fields above.

### Currency

Every account also records its currency. The form opens on INR, the currency of India, and the supplier changes it for an account held in another currency.

## Tax and company registrations

| Registration | Requirement | Format | Notes |
| --- | --- | --- | --- |
| PAN | Required | 10 characters, letters and digits | 10 characters, for example, AAAPZ1234C. |
| GSTIN | Suggested | 15 characters, letters and digits, GSTIN checksum | 15 characters. |

After a registration is saved, Coverbase checks it against the Indian GST portal in the background. That check never blocks the supplier: it annotates the record once it completes, and a reviewer can retry it.

## Where these rules come from

Oracle Fusion Cash Management 26c IN validations; RBI IFSC format.

The rules on this page are confirmed against a primary source, so they are enforced strictly.

Configuration version `2026.10.3`. Your organization can override any of these rules for its own suppliers.
