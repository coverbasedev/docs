A supplier whose bank account is held in the United States sees the fields below. The country is chosen on the form, and changing it changes the fields, so a supplier is never asked for a detail their country does not use.

## Bank details

| Field | Requirement | Format | Notes |
| --- | --- | --- | --- |
| Bank name | Optional | up to 60 characters |  |
| Bank code | Optional | no length limit, digits only |  |
| Routing Transit Number | Required | 9 characters, digits only, ABA routing checksum | 9 digits, for example, 076401251. |
| Account number | Required | up to 17 characters |  |
| Check digit | Optional | no length limit, digits only | Optional. Only if your bank statement shows a separate check digit; leave blank if it does not. |
| SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, BOFAUS3N. Needed for a payment by wire. |
| Account type | Required | no length limit, one of: checking, savings | Checking unless the bank issued the account as a savings account. |
| Intermediary bank country code | Optional | 2 characters, letters only | Two-letter country code, for example, US. |
| Intermediary bank city | Optional | up to 60 characters |  |
| Account number at the intermediary bank | Optional | up to 34 characters |  |
| Intermediary bank name | Optional | up to 60 characters |  |
| Intermediary branch number | Optional | up to 30 characters |  |
| Intermediary IBAN | Optional | 15 to 34 characters, letters and digits, IBAN MOD-97 check |  |
| Intermediary SWIFT/BIC | Optional | 8 to 11 characters, letters and digits | 8 or 11 characters, for example, CHASUS33. |

### IBAN

the United States does not use IBANs. Accounts are identified by the fields above.

## Tax and company registrations

| Registration | Requirement | Format | Notes |
| --- | --- | --- | --- |
| EIN | Required | 9 characters, digits only | 9 digits, for example, 12-3456789. |

After a registration is saved, Coverbase checks it against the IRS TIN matching service in the background. That check never blocks the supplier: it annotates the record once it completes, and a reviewer can retry it.

## Country rules

- Postal codes are checked against the national format. A postal code that does not match produces a warning, not a rejection.

## Where these rules come from

Oracle Fusion Cash Management 26c US validations; IRS EIN prefix list.

The rules on this page are confirmed against a primary source, so they are enforced strictly.

Configuration version `2026.10.2`. Your organization can override any of these rules for its own suppliers.
