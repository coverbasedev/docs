The EcoVadis connector feeds the [Certificate Vault](/products/certificate-vault). You bring your own EcoVadis subscription, and Coverbase reads it with your credentials once a day.

<Note>
  EcoVadis is a partner API. The request paths and field names Coverbase uses are its reading of the partner documentation and need checking against your account. If the response does not have the shape Coverbase expects, the sync stops and records the error. It never treats such a response as an empty list, because an empty pull archives every certificate the network supplied.
</Note>

## What it does

EcoVadis publishes a sustainability scorecard for each rated company. Coverbase reads the scorecards shared with your account and writes each as an **EcoVadis rating**, with its ESG score, into the vault.

- **Matched to your vendors.** Each record is matched to a vendor by a match recorded on an earlier run, then by its domain (walking up to the parent domain, never down), then by its exact legal name. A record that matches no vendor is skipped.
- **Kept current.** A network record is keyed by the network's ID and the certificate type. A complete pull archives records the network no longer returns.
- **Read by prequalification.** Network grade, network status and safety or ESG figure conditions in your [prequalification rule sets](/user-guides/certificate-vault#step-4-write-a-prequalification-rule-set) read these records. Only current records count.

## Authentication

EcoVadis issues a token from `https://api.ecovadis-survey.com/EVToken` for an API user name and password. Coverbase reads scorecards from `/v2/scorecards`.

1. Ask EcoVadis for API access for your account.
2. Note the API user name and password.

## Set up in Coverbase

1. Open **Configuration → External Integrations** and click **EcoVadis**.
2. Enter **Username** and **Password**.
3. Click **Save**, then **Test connection**.
4. On the **Certificates** page, the **Networks** card shows EcoVadis as connected, with its certificate count and last sync. Click **Sync now** for the first pull.

If a sync fails, the panel and the **Networks** card show **The last sync failed** with the reason. Only Coverbase's own error messages are stored, never a credential or the provider's response. **Remove** deletes the stored credentials; certificates already pulled stay.
