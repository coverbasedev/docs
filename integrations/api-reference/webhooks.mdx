The Webhooks API manages webhook subscription records and can send a manual test delivery to a registered endpoint. For the delivery format, signature verification, and the event catalog, see the [Webhooks](/integrations/webhooks) reference.

All endpoints are org-scoped to the API key. See [API conventions](/conventions) for authentication and the error envelope.

## Register a webhook

<ParamField path="method" type="POST">
  `POST /v1/webhooks`
</ParamField>

Creates a webhook subscription. Returns `201 Created`.

### Request body

<ParamField body="url" type="string" required>
  The endpoint Coverbase will POST to. **Must start with `https://`.**
</ParamField>

<ParamField body="events" type="string[]" required>
  Event type strings to subscribe to. This is a free-form list of strings; it is **not** validated against a fixed enum at registration time. Use the exact event values from the [event catalog](/integrations/webhooks#event-catalog) (e.g. `Vendor.Created`).
</ParamField>

<ParamField body="secret" type="string" required>
  Shared secret used to sign deliveries (HMAC-SHA256). **Must be at least 16 characters.** Write-only — it is never returned in any response.
</ParamField>

<ParamField body="description" type="string">
  Optional human-readable label.
</ParamField>

<ParamField body="enabled" type="boolean">
  Defaults to `true`. When `false`, the subscription is created in a disabled state.
</ParamField>

### Example request

<CodeGroup>

```bash cURL
curl -X POST "https://api.coverbase.app/v1/webhooks" \
  -H "Authorization: Bearer ak_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://hooks.example.com/coverbase",
    "events": ["Vendor.Created", "Vendor.Updated", "Assessment.Created"],
    "secret": "whsec_a1b2c3d4e5f6a7b8c9d0e1f2",
    "description": "Primary GRC integration"
  }'
```

```python Python
import os
import secrets
import requests

API_KEY = os.environ["COVERBASE_API_KEY"]
BASE_URL = "https://api.coverbase.app"

webhook_secret = f"whsec_{secrets.token_hex(24)}"  # >= 16 chars

resp = requests.post(
    f"{BASE_URL}/v1/webhooks",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://hooks.example.com/coverbase",
        "events": ["Vendor.Created", "Vendor.Updated", "Assessment.Created"],
        "secret": webhook_secret,
        "description": "Primary GRC integration",
    },
    timeout=30,
)
resp.raise_for_status()
print(resp.json())
```

</CodeGroup>

### Example response

`201 Created`:

```json
{
  "id": "cbwh_d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9",
  "url": "https://hooks.example.com/coverbase",
  "events": ["Vendor.Created", "Vendor.Updated", "Assessment.Created"],
  "description": "Primary GRC integration",
  "enabled": true,
  "created_at": 1746576000
}
```

<Warning>
  The `secret` is never returned after creation. Store it at registration time. If lost, set a new one via the update endpoint.
</Warning>

### Response fields

<ResponseField name="id" type="string">
  Webhook ID (`cbwh_...`).
</ResponseField>

<ResponseField name="url" type="string">
  The registered HTTPS endpoint.
</ResponseField>

<ResponseField name="events" type="string[]">
  Subscribed event strings.
</ResponseField>

<ResponseField name="description" type="string | null">
  The label, if set.
</ResponseField>

<ResponseField name="enabled" type="boolean">
  `true` when the subscription is active.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Unix timestamp (seconds) when the webhook was created.
</ResponseField>

### Error responses

| Status | Body | When |
| ------ | ---- | ---- |
| 400 | `{"detail": {"code": "weak_secret", "message": "Secret must be at least 16 characters."}}` | `secret` is shorter than 16 characters. Checked before the URL. |
| 400 | `{"detail": {"code": "invalid_url", "message": "Webhook URL must use HTTPS."}}` | `url` does not start with `https://`. |
| 422 | Standard validation error | Required fields missing or wrong type. See [API conventions](/conventions#validation-errors). |

## List webhooks

<ParamField path="method" type="GET">

</ParamField>

```json
{
  "data": [

      "id": "cbwh_d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9",

      "description": "Primary GRC integration",
      "enabled": true,
      "created_at": 1746576000
    }
  ]
}
```

## Update a webhook

<ParamField path="method" type="PATCH">
  `PATCH /v1/webhooks/{webhook_id}`
</ParamField>

Updates a webhook subscription. Only the fields you include are changed; omitted or `null` fields are left unchanged. Returns the updated webhook (same shape as the create response).

### Request body

<ParamField body="url" type="string">
  New endpoint. If provided, must start with `https://`.
</ParamField>

<ParamField body="events" type="string[]">
  Replace the subscribed event list.
</ParamField>

<ParamField body="secret" type="string">
  Rotate the signing secret. If provided, must be at least 16 characters.
</ParamField>

<ParamField body="description" type="string">
  Update the label.
</ParamField>

<ParamField body="enabled" type="boolean">
  Enable or disable the subscription.
</ParamField>

### Example requests

```bash Update events
curl -X PATCH "https://api.coverbase.app/v1/webhooks/cbwh_d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9" \
  -H "Authorization: Bearer ak_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "events": ["Vendor.Created", "Vendor.Updated", "Assessment.StatusChanged"] }'
```

```bash Rotate the secret
curl -X PATCH "https://api.coverbase.app/v1/webhooks/cbwh_d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9" \
  -H "Authorization: Bearer ak_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "secret": "whsec_newsecretvalueatleast16" }'
```

### Error responses

| Status | Body | When |
| ------ | ---- | ---- |
| 400 | `{"detail": {"code": "weak_secret", "message": "..."}}` | A new `secret` shorter than 16 characters was supplied. |
| 400 | `{"detail": {"code": "invalid_url", "message": "Webhook URL must use HTTPS."}}` | A new `url` not starting with `https://` was supplied. |
| 404 | `{"detail": {"code": "webhook_not_found", "message": "Webhook not found."}}` | The `webhook_id` does not exist or is not in the API key's org. |

## Delete a webhook

<ParamField path="method" type="DELETE">
  `DELETE /v1/webhooks/{webhook_id}`
</ParamField>

Archives (soft-deletes) the webhook subscription. Returns `204 No Content`.

```bash cURL
curl -X DELETE "https://api.coverbase.app/v1/webhooks/cbwh_d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9" \
  -H "Authorization: Bearer ak_live_xxx"
```

| Status | Body | When |
| ------ | ---- | ---- |
| 204 | _(empty)_ | Archived successfully. |
| 404 | `{"detail": {"code": "webhook_not_found", "message": "Webhook not found."}}` | The `webhook_id` does not exist or is not in the API key's org. |

## Test a webhook

<ParamField path="method" type="POST">
  `POST /v1/webhooks/{webhook_id}/test`
</ParamField>

Enqueues a test delivery to the webhook's URL. The delivery is dispatched asynchronously, so the response confirms the test was **enqueued** — it does not contain the receiver's HTTP status.

### Request body

<ParamField body="event_type" type="string">
  Event type string to send in the test delivery. Defaults to `webhook.test`.
</ParamField>

### Example request

```bash cURL
curl -X POST "https://api.coverbase.app/v1/webhooks/cbwh_d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9/test" \
  -H "Authorization: Bearer ak_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "event_type": "Assessment.Created" }'
```

### Example response

```json
{
  "event_id": "cbevt_test_8b3c1a4d9e7f2c5b6a8d1e3f9c7b4a2e",
  "delivered": true,
  "response_status": null,
  "response_time_ms": null,
  "attempted_at": 1746576180
}
```

<Note>
  `delivered` reflects that the test was **enqueued**, not that the receiver accepted it. `response_status` and `response_time_ms` are always `null` on this response because delivery happens out of band. The test payload's `data` is `{"test": true}`.
</Note>

### Error responses

| Status | Body | When |
| ------ | ---- | ---- |
| 404 | `{"detail": {"code": "webhook_not_found", "message": "Webhook not found."}}` | The `webhook_id` does not exist or is not in the API key's org. |
